# Bilder för landningssidan

Förhandsvisningen på startsidan förväntar sig dessa tre filer:

- `preview-tvattmaskin.png`: källprodukt med **vit** bakgrund (vänster, övre)
- `preview-torktumlare.png`: källprodukt med **vit** bakgrund (vänster, nedre)
- `preview-bundle.png`: färdig, frilagd bundle med plusset inbakat, **transparent** PNG (höger)

Ladda upp dem med exakt dessa namn så visas de automatiskt i hero-sektionens
förhandsvisning. De två källbilderna visas mot vit bakgrund; resultatbilden
mot ett rutmönster som visar transparensen.
