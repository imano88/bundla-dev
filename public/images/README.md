# Bilder för landningssidan

Förhandsvisningen på startsidan förväntar sig dessa tre filer:

- `preview-tvattmaskin.png`: frilagd källprodukt (vänster, övre)
- `preview-torktumlare.png`: frilagd källprodukt (vänster, nedre)
- `preview-bundle.png`: färdig bundle med plusset inbakat (höger)

Ladda upp dem med exakt dessa namn (transparent PNG) så visas de automatiskt
i hero-sektionens förhandsvisning.
